# Pick'N'Eat Website

Static website for Pick'N'Eat – Amul Icecreams.

Files:
- index.html
- styles.css

The product catalogue is stored in the JavaScript section of index.html so the site can be deployed directly to Cloudflare Pages.

Google Maps listing:
https://maps.app.goo.gl/xwJEqc8thWthagxH7?g_st=iw

Important:
- Customer-facing prices use MRP from the supplied bills.
- Distributor purchase rates, invoice totals, GST details and supplier/bank details are intentionally not displayed.
- Replace the placeholder gallery cards with your own shop/product photos when available.
