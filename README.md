# Pick'N'Eat Website

A responsive static website for Pick'N'Eat – an independent Amul ice-cream retailer/distributor website.

## Included
- Responsive homepage
- Product catalogue with category filters
- Search
- "Add to Pick" cart stored in the browser
- Combo packs
- Mobile navigation
- Contact / WhatsApp placeholders
- No framework or paid dependency

## Important
The product names/prices in this starter are demo content. Verify your actual inventory and current prices before publishing.
Replace the WhatsApp button with your real business WhatsApp number.
Use Amul branding/product imagery only if you have permission/authorization appropriate for your business.

## Deploy
This is a static site. Upload the contents of this folder to a static host such as Cloudflare Pages.
The main file is `index.html`.
